# Swiss Trip

Day-by-day itinerary for a Switzerland trip, 16–19 Oct 2026: times, how long at each stop,
estimated costs (CHF, for two), drive distances, and Google Maps / Google Search links.

```bash
npm install
npm run dev   # http://localhost:3000
```

The itinerary data lives in `lib/plans/switzerland.ts`. Costs are estimates — verify prices
and opening hours on the official sites before travelling.
