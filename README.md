# Swiss Trip

Day-by-day itinerary for a Switzerland trip, 16–19 Oct 2026: times, how long at each stop,
estimated costs (CHF, for two), drive distances, and Google Maps / Google Search links.

It's a single file, `index.html` — no build, no server, no dependencies. Open it in any
browser (phone included) or send the file to someone. The itinerary data is the JSON block
inside the file (`<script id="plan">`); edit it there.

Costs are estimates — verify prices and opening hours before travelling.

## Rain plan

`index.html` has a switch at the top: **Plan A (dry)** and **Rain plan (Sat & Sun)**. You can also open
`index.html?plan=rain` directly. `swiss-trip.kml` and `swiss-trip-rain.kml` import into Google My Maps.
